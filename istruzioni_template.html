🏋️ Istruzioni: Come creare una scheda per l'app

Questa guida spiega come compilare il file template_scheda.csv per produrre una scheda che, una volta convertita con converter.html, diventa un'app mobile pronta per il tuo cliente.

✏️ Apri Editor guidato ⬇️ Scarica template CSV L'editor è il modo più semplice per creare la scheda

1. Strumenti necessari

Apri il CSV con uno di questi programmi:
  • Google Sheets — File → Importa → seleziona il CSV (separatore virgola)
  • Microsoft Excel — apri direttamente il file .csv
  • LibreOffice Calc — apri il file, seleziona separatore "virgola"

2. Struttura del file — le 5 colonne

A — Esercizio B — Prog A C — Prog B D — Prog C E — Link
(vuota) Warm-up (vuota) (vuota) (vuota)

Affondi 3x12 BW 3x12 BW 3x10 BW
La prima riga del file deve contenere esattamente la parola Esercizio nella colonna A. Non rinominarla.

3. Come aggiungere una sezione (gruppo di esercizi)

Per creare un'intestazione di sezione (es. "Parte Inferiore", "Warm-up"):

  • Colonna A: lascia vuota
  • Colonna B: scrivi il nome della sezione
  • Colonne C, D, E: lascia vuote

I colori delle sezioni nell'app vengono assegnati automaticamente in base al nome:

Nome contiene…Colore nell'app
warm, riscaldamento🟡 Giallo
inferior, basso, gambe, leg🔵 Blu
superior, alto, petto, schiena, spalle, braccia🟣 Viola
qualsiasi altro nome🟢 Verde

Puoi combinare più formati nella stessa cella: es. 3x10 70% R60" → 3 × 10 serie 70% ⏱ 60"
Se nessun formato viene riconosciuto, il testo viene mostrato così com'è.
Un esercizio può avere parametri diversi per i 3 programmi (A, B, C). Se per un programma l'esercizio non è previsto, lascia la cella vuota.

5. Link video (colonna E)

Inserisci un URL completo che inizia con https://. Se presente, nell'app apparirà un pulsante ▶ Video. Lascia vuota se non hai un video di riferimento.

6. Esportare come PDF

Google Sheets: File → Scarica → PDF → imposta orientamento Orizzontale → scarica
Microsoft Excel: File → Esporta → Crea PDF/XPS → Salva
LibreOffice Calc: File → Esporta come PDF → Esporta
Assicurati che tutte le 5 colonne siano visibili nel PDF (non tagliate). Usa orientamento Orizzontale se necessario. Evita di unire celle o usare layout multi-colonna.

7. Convertire il PDF nell'app

  1. Apri converter.html nel browser
  2. Trascina il PDF appena creato
  3. Clicca ⬇️ Scarica HTML
  4. Invia il file HTML al tuo cliente — si apre direttamente dal telefono
